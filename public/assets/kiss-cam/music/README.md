# Kiss Cam LED music

Music plays on the **laptop / LED screen** (venue speakers), not on the phone camera.

## Option A — Choose a file in the app (recommended)

1. Open Kiss Cam on the LED laptop.
2. In **Controls → Music**, tap **Choose music**.
3. Pick an MP3 / M4A / WAV / OGG from this computer.
4. Turn **Music** ON, then press **Start Kiss Cam**.

The file stays in this browser tab only (not uploaded to a server).

## Option B — Bundled default theme

Place a file named:

`theme.mp3`

in this folder (`public/assets/kiss-cam/music/theme.mp3`).

Kiss Cam will auto-detect it and use it when no custom file is chosen.

Use only tracks you have rights to play at the event.
